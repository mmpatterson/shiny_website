# Personal Website

This is my personal website built using **R Shiny**. It's a simple, interactive web app that showcases a bit about me, my work, and what I'm passionate about.

## What's Inside

- **About Me**: A brief overview of who I am.
- **Projects**: A portfolio of data science projects I've worked on, displayed using interactive cards.
- **Resume**: A downloadable copy of my resume.
- **Contact**: Social links to get in touch.
